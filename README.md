# Micra Drone

Minecraft (NeoForge 21.1.238 / Minecraft 1.21.1) mod for programming
education. Players write code in a custom Python-like language to control a
farming drone, automate crop work, and unlock progression — inspired by
[The Farmer Was Replaced](https://store.steampowered.com/app/2060160/The_Farmer_Was_Replaced/).

日本語の遊び方ガイドは下の [遊び方](#遊び方) を参照してください。

## Requirements

- Java 21 (JDK)
- Minecraft 1.21.1 / NeoForge 21.1.238
- (任意) AIチャット機能を使う場合のみ: ゲームクライアントを動かすPCに
  Claude Code（`claude`コマンド）がインストール・ログイン済みであること
  （Claude Pro/Maxのアカウント）。無くてもmodの他の機能はすべて動く。

## Development

```
./gradlew runClient
```

First run downloads and decompiles Minecraft; this can take a while.

```
./gradlew build
```

builds `micradrone-<version>.jar` under `build/libs/` and runs the JUnit test
suite (the interpreter, farm rules, and other Minecraft-independent logic are
covered there; GUI/world behavior needs manual verification in-game).

## 遊び方

### 1. 入手する

2つの専用ブロックをクラフトする。

**Drone Controller**（ドローンコントローラ、鉄インゴット4・ガラス4・レッドストーン1、
下図の配置でクラフト）

```
[鉄] [ガラス] [鉄]
[ガラス] [レッドストーン] [ガラス]
[鉄] [ガラス] [鉄]
```

**Corner Marker**（コーナーマーカー、金インゴット4・ガラス1）

```
      [金]
[金] [ガラス] [金]
      [金]
```

### 2. 設置してプロットを作る

Drone Controllerを地面に置き、そこから斜め方向に好きな距離だけ離れた場所に
Corner Markerを置く。この2つのブロックが対角線上（斜め45度、コーナー
マーカーの水平距離が一致していれば多少の高低差はOK）にあれば、その正方形の
範囲がドローンの耕作エリア（プロット）として認識される。マーカーが無い場合は
コントローラの南東方向5x5マスがデフォルトのプロットになる。

Drone Controllerは地表（草ブロックなどの上）に置くのがおすすめ。この場合、
コントローラ本体は地表に見えたまま、耕作エリアは自動的に1段下と判定される。
（土や耕地と同じ高さに埋め込む昔ながらの置き方もそのまま使える。）

Corner Markerは置いた瞬間に一意な番号（1, 2, 3, ...）を自動で持つ。金床で
名前を付けてから置くと、その名前で識別できるようになる（他のマーカーと
同じ名前は拒否され、チャットで理由が表示される）。名前を変えたい・消したい
場合は、マーカーを壊して（付けた名前・番号を保持したまま道具箱に戻る）
金床で付け直し、再度置けばよい。**今のIDはマーカーを右クリック（Shop画面）
すると確認できる**ので、スクリプトの`get_plot_id()`で使う前に見ておける。

### 3. スクリプトを入手する（エンチャントテーブル）

スクリプトは「スクリプトの巻物」アイテムに書く。空の巻物は紙3枚・羽根1・
インク袋1でクラフトできる。

サンプルスクリプトやコマンド一覧（ヘルプ）は、**エンチャントテーブル**から
授かる。エンチャントテーブルを右クリックしてバニラのエンチャント画面を開き、
そのアイテムスロットに空の巻物をドラッグ&ドロップで入れると、候補一覧の
画面に自動で切り替わる（バニラの本を持って右クリックではなく、スロットに
入れるのがポイント）。ラピスラズリと引き換えに書き込んでもらえる。
テーブルの周りに置く**本棚の数が多いほど、選べる高度なサンプルが増える**
（バニラのエンチャントと同じ仕組み）。テーブル周りのチェスト・シュルカー
ボックス・彫刻入りの本棚などに書き込み済みの巻物を入れておくと、それを
ラピス1個で複製することもできる。

何も狙わずに巻物を右クリックすると、本と羽ペンと同じ画面で自由に書ける
（署名は不要で、何度でも書き直せる）。

### 4. コントローラを右クリックしてIDEを開く

コントローラを右クリックすると、ゲーム内IDE（統合開発環境）が直接開く。
左半分がスクリプトエディタ、右半分は上空から見た畑のライブ映像（実際の
ブロックの様子がそのまま見える）。

- 置いたばかりのコントローラでも、そのまま書いて **Save & Run** できる。
  コントローラ自身が1本のスクリプト（一覧の先頭の「Controller script」）を
  持っていて、最初はそれが編集・実行対象になっているため。巻物は
  スクリプトを持ち運んだり共有したりするためのもの。
- 右側の **List** ボタンで、畑のライブ映像とスクリプト一覧の表示を
  切り替えられる。一覧から1本選ぶとそれが編集・実行対象になる。
- スクリプトは、コントローラからコーナーマーカーの方向（東西・南北の
  それぞれの軸上、コーナーマーカーと同じ距離である必要はない）に
  チェスト・シュルカーボックス・彫刻入りの本棚などを置くと、その中の
  巻物が一覧に並ぶ（スクリプトライブラリ）。プロットの大きさを後から
  変えても置き直す必要はない。巻物は金床でリネームでき、一覧にはその
  名前で表示される。空の巻物をライブラリに置いておくと、一覧に
  「✎」マーク付きの新規スクリプトとして現れ、選ぶとそのまま書き込みを
  始められる。**自分のインベントリに持っている巻物も一覧に並ぶ**（置き場所を
  用意しなくても、持ち歩いている巻物をそのまま編集・実行できる。他の
  プレイヤーには見えない、自分専用の一覧項目）。
- **コントローラにレッドストーン信号（レバーなど）を送ると、ON=選択中の
  スクリプトを実行、OFF=停止**できる（GUIを開かずに動かせる）。IDE内にも
  Save / Run / Save & Run / Stopボタンがあり、編集しながらすぐ試せる。
  選択中が「自分のインベントリの巻物」の場合、レバーはそのコントローラを
  最後にRunした人のインベントリから読む（その人がログイン中で、巻物を
  持ったままである必要がある）。レバー運用が主なら Controller script か
  ライブラリのチェストに置いた巻物を選んでおくと確実。
- デバッガ機能もある: エディタ左端（行番号の横）をクリックすると
  ブレークポイントを設定でき、Pause / Resume / Step / Step Outで
  1行ずつ実行状況を追える。
- コントローラ自体も金床でリネームでき、そのエイリアスがスクリプトの
  保存フォルダ名にも反映される。
- コントローラは待機中/実行中で見た目が変わり（実行中は画面がコード表示に
  切り替わる）、設置した人の方を向く。
- 複数人で同時に同じコントローラのログ・デバッグ状況を見られる（マルチ
  プレイ対応）。収穫の実績は、そのスクリプトの実行を開始した人に記録される。
- **Chat**ボタンで、AI（自分のマシンにログイン済みのclaude CLI、APIキー不要）
  に直接スクリプトの質問ができる。**前提**: ゲームを動かしているPCに
  Claude Code（`claude`コマンド）がインストール済みで、Claude Pro/Maxの
  アカウントでログイン済みであること（`npm install -g @anthropic-ai/claude-code`
  → `claude login`）。modには何も同梱されず、サーバー側では何も動かない。
  無い場合はChatタブを開いた時に赤字でその旨が出るだけで、modの他の機能は
  すべて普通に使える。質問には、現在編集中のスクリプト・コマンド
  リファレンス（ヘルプ1/3と2/3）・直前の実行エラー・畑の位置とグリッド座標の
  対応・このコントローラのアンロック状況と所持ポイント・未購入品の価格が
  自動で添えられるので、「ニンジンはShopで小麦20で解放してから」のような
  前提込みで答えてくれる。
  - 送信中は「AI: thinking...」と表示され、**Esc**で中断できる（送った文面は
    入力欄に残るので、打ち間違いを直してそのまま送り直せる）。
  - **回答にコードが含まれると、その場でエディタが差分表示に変わる**（Cursor
    と同じ流れ）: 消える行は赤、増える行は緑で元の行の間に並ぶ。変更ブロック
    ごとに右端の「x Reject」で個別に却下でき、Chatタブの「Accept rest」で
    残りをまとめて適用、「Reject all」で全部取り消す。差分を見ている間は
    エディタは読み取り専用。
  - 会話履歴はコントローラごと・ワールドごとに自動保存され、次回Chatを開くと
    再開する（ローカル保存のみ、他プレイヤーとは共有されない）。「Compact」
    ボタンで会話を要約して仕切り直せる。
  - 既定ではAIはファイル編集・コマンド実行等のツールを一切使えない安全モードで
    動く。**Danger**トグルをONにすると、プレイヤー自身の端末でclaudeを直接叩く
    のと同じフル権限になり、さらに**回答のコードは差分確認なしでそのまま
    エディタに適用**される（「AIに任せる」モード。直後に出る「Undo AI change」で
    1手だけ戻せる）。Chat画面を開いている間だけ有効。
  - **Region Pointer**（コンパス+棒でクラフト）を持ってブロックを左クリック
    （始点）→右クリック（終点）すると、選んだ範囲がワールド内に水色の箱で
    表示され（始点を決めた後は照準先まで箱が伸びる）、次にChatを開いた瞬間に
    その座標が入力欄へ入る。AIが範囲内のブロックの中身を知りたいときは、
    こちらから教えなくてもAI自身がツール経由で確認する。

### 5. スクリプトを書く

構文はインデント方式のPython風。例えば付属のサンプル
`till_and_plant`（エンチャントテーブルで本棚3冊から授かれる）は次のような
内容（往復しながら畑全体を耕して植える）:

```python
# Tills and plants wheat across the whole plot using a snake path (no backtracking needed).
size = get_world_size()
going_east = True
row = 0
while row < size:
    col = 0
    while col < size - 1:
        till()
        plant("wheat")
        if going_east:
            move("east")
        else:
            move("west")
        col = col + 1
    till()
    plant("wheat")
    if row < size - 1:
        move("south")
    going_east = not going_east
    row = row + 1
print("planted the whole plot")
```

`move()` / `till()` / `plant()` / `harvest()` でドローンを動かし畑を耕す。
`can_harvest()` / `is_rotten()` / `get_pos_x()` / `get_points()` などの
読み取り系コマンドで状況を判断する。詳しい一覧は、エンチャントテーブルで
授かれる3本のヘルプ巻物（1/3 基本コマンド、2/3 ショップ・コレクション型、
3/3 IDEと巻物の使い方）で確認できる（いずれも本棚0冊・ラピス1個で
入手可能、上の「3. スクリプトを入手する」参照）。

さらに `get_ground()` / `get_block_above()` / `get_time()` / `get_weather()` /
`get_biome()` / `get_light()` でMinecraftの世界そのものを読み取れる。
これらを使うと「決まった手順をなぞるだけ」ではなく、その場の地形や天気を
見て判断するスクリプトが書ける。`get_plot_id()` は今のプロットのコーナー
マーカーのID（金床で付けた別名、無ければ自動採番のID）を返すので、
複数のプロットを持っているときにスクリプト側で見分けられる:

```python
ground = get_ground()
if ground == "farmland":
    plant("wheat")
elif ground == "dirt":
    till()
    plant("wheat")
else:
    print("ここには植えられない")
    print(ground)
```

ブロック名・バイオーム名はvanillaのものなら `"dirt"` のように短い名前、
MODが追加したものだけ `"micradrone:rotten_pumpkin"` のように名前空間が付く。

スクリプトを選んで **Run** を押すと実行され、ログ欄に `print()` の出力が
流れる。**Stop** でいつでも安全に止められる。

### 6. ポイントを稼いでショップでアンロックする

収穫すると作物ごとにポイントが貯まる（IDE画面上部に常時表示）。**Corner
Marker を右クリック**するか、**IDE画面右上の Shop ボタン**からショップ画面
を開き、貯めたポイントで新しい作物（carrot、pumpkin）をアンロックできる。
アンロックした作物は種なしで植え放題。未アンロックの作物でも、最後にRunした
プレイヤーのインベントリに本物の種（carrotはニンジン、pumpkinはカボチャの種）が
あれば `plant()` のたびに1個消費して植えられる。どちらも無ければ `plant()` は
失敗する。

pumpkinは植えたマスでその場に実り（本家 *The Farmer Was Replaced* と同じ）、
実る瞬間に約20%の確率で「腐ったかぼちゃ」になる。腐ったマスは収穫しても
ポイントが入らず、しかも下記の巨大化を止めてしまうので、`is_rotten()` で
見つけ次第そのまま `plant("pumpkin")` で植え直す（harvest不要）のがコツ。

実ったpumpkinが正方形（2x2以上）に揃うと自動的に「巨大かぼちゃ」に変わり、
となりが実るたびにより大きな正方形へ組み直される（2x2 → 3x3 → … → 畑
いっぱい）。どこか1マスを収穫すると一辺nで n³（n≥6は 6n²）ポイントがまとめて
入る。1マスずつなら1ポイントなので、かぼちゃのスコアはほぼ融合で決まる。
巨大かぼちゃを手で壊すと融合が解け、残りは普通の実ったかぼちゃに戻る。

### 7. 進捗（実績）を解除する

Drone Controller / Corner Marker の入手、作物のアンロック、収穫数の節目
（10個・100個・1000個ごと、作物別）で進捗（Advancement）が解除される。
マイクラの「進捗」画面に専用タブが表示される。

### プロットの仕様メモ

- 耕作エリア内の耕地は常に最大湿度に保たれる（水源が無くても乾かない・
  dirtに戻らない）。
- プロット内の未成熟な作物は約5秒ごとに自動で成長が早まる
  （スクリプトを実行していなくても常時作用）。
