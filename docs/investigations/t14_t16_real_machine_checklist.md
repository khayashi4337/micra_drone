# T-14/T-16: 実機確認チェックリスト

AIチャット支援機能のWave 5/6の最終確認。ここまでの全タスク(SPK-1〜3、
T-1〜T-15)は実装・コミット済みで、ビルド成功・JUnit 294件パスを実測確認
済み。ただしT-14(get_block_snapshot統合確認)とT-16(異常系E2E確認)は
実際にMinecraftクライアントを起動してGUIを操作する必要があり、この
Bash専用の作業環境では実施できない(画面操作の手段が無い)。以下は林さんに
実機で確認していただくためのチェックリスト。

## 事前準備

- [ ] `claude` CLIがこのマシンにインストール済み・ログイン済みであることを
  確認(`claude --version`が動けばOK)
- [ ] `gradlew runClient`でMinecraftを起動し、Drone Controllerを新規設置
- [ ] `micra_drone/mcp-config.json`がゲームディレクトリ配下
  (`.minecraft/micradrone/mcp-config.json`)に生成されることを、Chatを
  一度開いた後に確認(BlockSnapshotToolServerの遅延起動確認)

## T-14: get_block_snapshot 統合確認

1. [ ] コントローラを右クリック→IDEが開く→**Chat**タブを押す
2. [ ] 入力欄に何か書いて**Send**を押す→数秒後にAIから応答が返ってくる
   (初回は`claude`の起動コストで数秒〜十数秒かかる想定)
3. [ ] Region Pointer(コンパス+棒でクラフト)を持ち、畑のブロックを
   左クリック→別のブロックを右クリック
4. [ ] Chatを開く→入力欄に座標範囲テキスト(例: `(1,64,2)~(3,64,4)`)が
   自動で入っていることを確認
5. [ ] 「この範囲に何が植わっている?」のように、AIに範囲の中身を尋ねる
   質問を送る→AIが自分でget_block_snapshotツールを呼び、実際のブロック名
   (`minecraft:farmland`等)を答えに含めてくることを確認(人間が中身を
   教えなくても良いことの確認)
6. [ ] AIの回答に```コードブロックが含まれる場合、**Insert #1**ボタンで
   エディタに反映されることを確認

## T-16: 異常系確認

1. [ ] **未ロード範囲**: ワールドの遠く離れた(読み込まれていない)座標を
   Region Pointerで選ぶのは物理的に無理なので、代わりにAIへのチャットで
   「(100000,64,100000)から(100000,64,100000)の範囲を見て」のように
   明らかに未ロードな座標を直接指定させ、「unavailable」という趣旨の
   応答が返ってくる(クラッシュしない)ことを確認
2. [ ] **送信中に画面を閉じる**: Sendを押した直後(応答待ち中)にIDE画面を
   Escで閉じる→クラッシュしないこと、再度開いても問題なく使えることを確認
3. [ ] **danger トグル**: OFFのままファイル操作を頼むような質問をしても
   実際には何も起きないこと(AIが「ツールが無い」という趣旨で断る)を確認。
   ONにしてから同じ質問をすると実際に動作が変わる(挙動が変わることだけ
   確認できればよい、破壊的な操作は試さないこと)
4. [ ] **履歴破損からの復旧**: (任意、時間があれば)
   `.minecraft/micradrone/chat/`配下の該当ファイルを手動で壊れた内容に
   書き換えてからChatを開く→クラッシュせず空の会話から始まることを確認
5. [ ] **resume**: 一度会話してChatを閉じ、IDEを閉じて再度開く→前回の
   会話が復元されていることを確認
6. [ ] **compact**: 何度かやり取りした後に**Compact**ボタンを押す→
   会話が要約1件に置き換わることを確認
